# Ostatni Rozdział
Jednostronicowa strona internetowa przygotowana dla konferencji chrześcijańskiej „Ostatni Rozdział”.
## Strona internetowa
🌐 https://ostatnirozdzial.pl

## Funkcjonalności
- Responsywny interfejs
- Informacje o wydarzeniu
- Prezentacja prelegentów
- Płynne przewijanie pomiędzy sekcjami

## Technologie
- React
- Vite
- CSS

## Instalacja
```bash
npm install
npm run dev
```

## Wdrożenie
Strona została wdrożona i jest publicznie dostępna pod adresem:

https://ostatnirozdzial.pl
